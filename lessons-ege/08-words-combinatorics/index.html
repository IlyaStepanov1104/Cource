Перестановки

Расставляем n разных объектов. Каждый используем ровно один раз.

n вариантов
n − 1
…
1 вариант

n! = n · (n − 1) · … · 1

0! = 1: пустой набор можно расставить одним способом.

Сочетания: выбрать места

Выбираем k мест из n. Порядок выбора мест не важен.

Выбрали 1, затем 3
Выбрали 3, затем 1

C(n, k) = n! / (k! · (n − k)!)

Это один набор {1, 3}. Деление на k! убирает разные порядки выбора одного набора.

Одинаковые буквы

А₁ А₂ Б
А₂ А₁ Б

После удаления меток оба результата — одно слово ААБ.

N = n! / (k₁! · k₂! · …)

k₁, k₂, … — количества одинаковых букв каждого вида. Делим на перестановки внутри каждой такой группы.

Не рядом: метод промежутков

□ Б □ В □ Г □

У m уже расставленных объектов есть m + 1 промежутков, включая края.

Чтобы k одинаковых букв не соседствовали, выбираем k разных промежутков.

C(m + 1, k), если k ≤ m + 1
