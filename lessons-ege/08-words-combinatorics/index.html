Немного теории

Правило произведения

Первый выбор
n вариантов
Второй выбор
m вариантов
для каждого первого

Нужно сделать И первый, И второй выбор

n · m

Пример: В кафе 3 вида кофе и 4 десерта.
Сколькими способами можно выбрать кофе и десерт?
3 · 4 = 12 способов

Правило суммы

Первый выбор
n вариантов
Второй выбор
m вариантов
не пересекаются с первыми

Нужно сделать ИЛИ первый, ИЛИ второй выбор

n + m

Пример: В кафе 3 вида кофе и 4 вида чая.
Сколькими способами можно выбрать один напиток?
3 + 4 = 7 способов

Перестановки

Расставляем n разных объектов по порядку. Каждый используем ровно один раз

1-е место
n вариантов
2-е место
n − 1
...
...
Последнее место
1 вариант

По правилу произведения умножаем число вариантов для каждого места

n · (n − 1) · … · 1 = Pn = n!

Pn — число перестановок n объектов
n! — произведение чисел от 1 до n

Пример: Сколькими способами можно расставить 4 разные книги на полке?
P4 = 4! = 4 · 3 · 2 · 1 = 24 способа

Размещения

Выбираем k объектов из n разных и расставляем по порядку. Порядок важен

1-е место
n вариантов
2-е место
n − 1
...
...
k-е место
n − k + 1

Как в перестановках, но заполняем только k мест, а не все n

n · (n − 1) · … · (n − k + 1)

Ank = n! / (n − k)!

n — всего объектов, k — сколько выбираем; A — размещения
Делим n! на (n − k)!, чтобы убрать лишние множители

Пример: Из 5 учеников выбирают старосту и заместителя. Сколькими способами?
A52 = 5 · 4 = 20 способов

Сочетания

Выбираем k объектов из n разных. Порядок не важен

Выбрали 1, затем 3
{1, 3}
Выбрали 3, затем 1
{1, 3}

Это один и тот же набор.
Значит каждую перестановку посчитали лишние разы. Разделим на Pk

Cnk = Ank / Pk

Cnk = n! / (k! · (n − k)!)

C — сочетания, n — всего объектов, k — размер набора
Деление на k! убирает разные порядки одного набора

Пример: Из 5 учеников выбирают 2 дежурных. Сколькими способами?
C52 = 5! / (2! · 3!) = 10 способов

Перестановки с повторениями

Расставляем n объектов, среди которых есть одинаковые. Их перестановка не создаёт новый вариант

Первый порядок
А₁ А₂ Б
Второй порядок
А₂ А₁ Б

Получили одно слово ААБ.
Если одинаковых букв k, каждое слово посчитано k! раз

n! / k!

Если групп одинаковых объектов несколько, делим на факториал каждой группы

Pn(k₁, k₂, …) = n! / (k₁! · k₂! · …)

k₁, k₂, … — размеры групп одинаковых объектов, их сумма равна n

Пример: Сколько разных слов можно составить из всех букв слова «МАМА»?
4! / (2! · 2!) = 6 слов

Размещения с повторениями

Заполняем k мест объектами n видов. Порядок важен, повторения разрешены

1-е место
n вариантов
2-е место
n вариантов
...
...
k-е место
n вариантов

После каждого выбора варианты не исчезают.
Для всех k мест количество вариантов одинаковое

n · n · … · n

A̅nk = nk

n — число доступных видов, k — число мест
Черта над A означает, что повторения разрешены

Пример: Сколько существует четырёхзначных PIN-кодов из цифр 0–9?
10 · 10 · 10 · 10 = 10⁴ = 10 000 кодов

Сочетания с повторениями

Выбираем k объектов из n видов. Порядок не важен, повторения разрешены

Первый выбор
А, А, Б
Второй выбор
Б, А, А

Это один набор: 2 буквы А и 1 буква Б.
Важно только количество объектов каждого вида

Изобразим k выбранных объектов звёздочками, а n видов разделим n − 1 перегородками

★★ | ★ |

Здесь k = 3, n = 3: взяли 2 объекта первого вида, 1 второго и 0 третьего

Сочетания с повторениями: формула

У нас k звёздочек и n − 1 перегородка

Всего символов
n + k − 1
Выбираем места звёздочек
k мест

Порядок одинаковых звёздочек не важен.
Значит, используем обычные сочетания

C̅nk = Cn+k−1k

C̅nk = (n + k − 1)! / (k! · (n − 1)!)

Пример: Выбираем 3 пирожных из 4 видов. Пирожные одного вида могут повторяться.
C̅43 = C63 = 20 способов

Не рядом: метод промежутков

Расставляем k одинаковых объектов так, чтобы они не стояли рядом

□ Б □ В □ Г □

Расставили m объектов
m + 1 промежутков
Добавляем k одинаковых
По одному в промежуток

Выбираем k разных промежутков из m + 1. Их порядок не важен

Cm+1k, если k ≤ m + 1

Пример: Сколькими способами можно вставить 2 буквы А в БВГ, чтобы А не стояли рядом?
C42 = 6 способов

Если остальные объекты тоже можно переставлять, их расположения считаем отдельно

Какую формулу выбрать?
