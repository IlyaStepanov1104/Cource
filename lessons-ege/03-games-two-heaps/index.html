Одна кучаДве кучи

moves2 числа4 пары
финишt >= FINISHсумма двух куч: is_finish(t)
can_win, must_loseне меняются

moves для двух куч

пару можно разобрать на две переменные, а вернуть - список пар

def moves(pos):
    a, b = pos
    return [(a + 1, b), (a, b + 1), (a * 2, b), (a, b * 2)]

is_finish(pos) - камней в двух кучах вместе не меньше 59

can_win и must_lose копируем с прошлого занятия, только t >= FINISH -> is_finish(t)

Перебор S

  • первая куча всегда 5, меняется только вторая: pos = (5, s)
  • S от 1 до 53 включительно: range(1, 53 + 1)
  • в if - строчка из шпаргалки, для №19 ещё цикл по ходам Пети
Граница включительно: иначе последнее S не проверим
