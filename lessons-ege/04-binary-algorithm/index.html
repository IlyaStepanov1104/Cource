На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R:

1. Строится двоичная запись числа N.

2. Если N чётное, к записи справа и слева дописываются по две единицы. Если N нечётное, справа дописываются два нуля, слева - единица.

3. Полученная запись - двоичная запись R.

Укажите наименьшее число R, превышающее 95, которое может быть результатом работы алгоритма.

Запись как строка

как вчера: число -> строка из 0 и 1 -> число

bin(13)            # '0b1101'
bin(13)[2:]        # '1101'
'1' + '1101' + '00'  # '1110100'
int('1110100', 2)  # 116
[2:] отрезает 0b. int(s, 2) - прочитать строку как двоичную

Сумма цифр

в двоичной записи сумма цифр = сколько единиц

s.count('1') % 2 == 0   # сумма чётная
