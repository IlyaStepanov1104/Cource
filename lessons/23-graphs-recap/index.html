Граф: вспоминаем

определение и хранение

Что такое граф

  • Граф - вершины (объекты) + рёбра (связи между ними)
  • Вершина (vertex) - один объект: город, человек, страница сайта
  • Ребро (edge) - связь между двумя вершинами
Три месяца не трогали графы - разберём всё на одном примере, который останется с нами весь урок

Наш граф на весь урок

Рёбра: 0-1, 1-2, 2-3, 3-0, 4-5

Матрица смежности

Наш граф в виде таблицы 6×6: 1 - есть ребро, 0 - нет 

matrix = [
    #0  1  2  3  4  5
    [0, 1, 0, 1, 0, 0],  # 0
    [1, 0, 1, 0, 0, 0],  # 1
    [0, 1, 0, 1, 0, 0],  # 2
    [1, 0, 1, 0, 0, 0],  # 3
    [0, 0, 0, 0, 0, 1],  # 4
    [0, 0, 0, 0, 1, 0],  # 5
]
matrix[u][v] == 1 - есть ребро между u и v. Просто, но ячеек всегда n×n, даже если рёбер почти нет

Список смежности

Тот же граф в виде словаря - только соседи, без пустых ячеек:

graph = {
    0: [1, 3],
    1: [0, 2],
    2: [1, 3],
    3: [2, 0],
    4: [5],
    5: [4],
}
Ключ = вершина, значение = список соседей. Быстрее матрицы, когда рёбер мало - а их обычно мало

Или в виде списка:

graph = [[1, 3], [0, 2], [1, 3], [2, 0], [5], [4]]

Вспоминаем DFS

поиск в глубину

Идея DFS

  • Идём вперёд, пока есть куда идти
  • Тупик (соседей нет или все посещены) - возвращаемся и пробуем другой путь
  • Как в лабиринте с ниткой

Зачем нужен visited

Наш граф циклический - квадрат 0-1-2-3-0. Без пометок DFS будет бегать по кругу вечно

0
->
1
->
2
->
3
->
0
!
Зашли в вершину - сразу добавили в visited. Иначе цикл 0-1-2-3-0 никогда не закончится

Трассировка DFS

старт: dfs(0)

1
dfs(0) - посещаем 0, идём в 1
2
dfs(1) - посещаем 1, идём в 2
3
dfs(2) - посещаем 2, идём в 3
4
dfs(3) - посещаем 3, соседи 2 и 0 уже visited - тупик, возврат
Порядок обхода: 0 1 2 3

dfs() - структура

def dfs(graph, v, visited):
    visited.add(v)
    ...  # что делаем с v

    for neighbor in graph[v]:
        if neighbor not in visited:
            ...
Сигнатура одна и та же для компонент и для двудольности - меняется только то, что делаем внутри

Компоненты и двудольность

две задачи поверх DFS

Несвязный граф

Наш граф распадается на 2 компоненты: квадрат 0-1-2-3 и пара 4-5

компонента 1
0 - 1 - 2 - 3 - 0
компонента 2
4 - 5

Как считать компоненты

1
Счётчик count = 0
2
Перебираем все вершины по порядку
3
Вершина не в visited - запускаем dfs(v), count += 1
4
DFS сама пометит всю компоненту как visited
На нашем графе: dfs(0) закрасит {0,1,2,3}, dfs(4) закрасит {4,5} - count = 2

Что такое двудольный граф

Вершины разбиты на два множества: L и R

  • Рёбра идут только между L и R
  • Внутри L или внутри R рёбер нет

Почему двудольность = только чётные циклы

В двудольном графе рёбра всегда идут между L и R - каждый шаг по циклу меняет сторону.

  • Чтобы цикл замкнулся на той же стороне, шагов должно быть чётное число
  • И наоборот: нечётный цикл раскрасить в 2 цвета без конфликта нельзя - мы видели это на треугольнике
Граф двудольный тогда и только тогда, когда в нём нет цикла нечётной длины

Двудольность: напоминание

  • Красим вершины в 2 цвета
  • Правило: сосед всегда другого цвета
  • Раскраска без конфликтов - граф двудольный

Квадрат vs треугольник

Квадрат 0-1-2-3-0

цвета: 0, 1, 0, 1 - без конфликтов

двудольный

Треугольник A-B-C

третья вершина всегда получит цвет соседа

не двудольный

Признак: нечётный цикл (3, 5, 7...) - в нём раскраска всегда конфликтует
