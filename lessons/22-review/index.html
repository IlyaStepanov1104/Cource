Задача 8 — зачем @property?

❌ Без property

class Hero:
    def __init__(self, hp):
        self.hp = hp

h = Hero(100)
h.hp = -50  # никто не мешает

✅ С property

class Hero:
    def __init__(self, hp):
        self._hp = hp

    @property
    def hp(self):
        return self._hp

    @hp.setter
    def hp(self, value):
        self._hp = max(0, value)
Property добавляет проверку/логику, а синтаксис обращения остаётся как у обычного атрибута

Игра — вспомни SOLID

Буква Принцип
S Single Responsibility — один класс = одна ответственность
O Open/Closed — открыт для расширения, закрыт для изменения
L Liskov Substitution — наследник заменяет родителя без сюрпризов
I Interface Segregation — много маленьких интерфейсов лучше одного большого
D Dependency Inversion — зависеть от абстракций, а не от реализаций

Задача 10

def sort_(a):
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

Какой это алгоритм и какая у него сложность?

Insertion sort, сложность O(n²) в худшем случае

Задача 15

graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D"],
    "D": []
}

def dfs(node, visited=None):
    if visited is None:
        visited = []
    visited.append(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(neighbor, visited)
    return visited

print(dfs("A"))

Какая тема? Тема: графы, обход в глубину (DFS)

Что выведет? ['A', 'B', 'D', 'C']
