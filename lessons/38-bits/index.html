Двоичная система

числа из лампочек

Как устроено 305

  • у каждой цифры свой вес
  • 305 = 3·100 + 0·10 + 5·1
  • соседний разряд тяжелее в 10 раз
  • цифры от 0 до 9

Двоичная: только 0 и 1

  • цифр всего две: 1 - лампочка горит, 0 - нет
  • вес соседа справа налево растёт в 2 раза: 1, 2, 4, 8, 16, ...
  • число = сумма весов горящих лампочек

101102 = ?10

16 + 4 + 2 = 2210

1310 = ?2

делимостаток
13 // 2 = 61
6 // 2 = 30
3 // 2 = 11
1 // 2 = 01
  • делим на 2, пока не станет 0
  • остатки читаем снизу вверх: 11012
  • проверка: 8 + 4 + 1 = 1310

Почему снизу вверх?

Сначала на обычных числах: разберём 305 на цифры

числоостаток = последняя цифрабез последней цифры
305305 % 10 = 5305 // 10 = 30
3030 % 10 = 030 // 10 = 3
33 % 10 = 33 // 10 = 0
  • цифры вышли в порядке 5, 0, 3 - справа налево
  • чтобы собрать 305, читаем их снизу вверх

То же в двоичной

числодвоичная записьостаток = последняя цифрабез последней цифры
13101101213 % 2 = 113 // 2 = 6
61011026 % 2 = 06 // 2 = 3
3101123 % 2 = 13 // 2 = 1
110121 % 2 = 11 // 2 = 0
  • % 2 - последняя цифра: все остальные лампочки весят 2, 4, 8... и делятся на 2 без остатка
  • // 2 - отрезать последнюю цифру, как // 10 у десятичных
  • первый остаток - самая правая цифра, поэтому читаем снизу вверх

А если числа покрупнее?

1 & 0 мы знаем. А что получится, если взять 13 & 24?

  • 13 и 24 - не биты, но каждое число - это ряд битов
  • биты одного веса стоят друг под другом - получились пары
  • к каждой паре применяем &, как к 1 и 0
  • из ответов собирается новый ряд - это и есть 13 & 24

Языки C и C++

  • C и C++ - тоже языки программирования, но «ближе к железу»
  • на них пишут то, что должно работать очень быстро: Windows и Linux, движки игр
  • даже сам Python написан на C: когда запускаешь программу, её выполняет программа на C
  • там берегут каждый бит памяти и каждую команду процессора - поэтому приём с лампочками там на каждом шагу

Зачем им биты

когда ты открываешь сайт, компьютеры пересылают друг другу пакеты. В каждом пакете - 6 флагов «да/нет» в одном числе

SYN + ACK («привет, слышу тебя») = 0100102 = 1810

  • 64 флага «да/нет» в одном числе - 8 байт; 64 отдельных «да/нет» - 64 байта
  • проверить или поставить бит - одна команда процессора
  • IP-адрес & маска подсети = адрес сети: тот самый & по столбцам

Бэкенд: права пользователя

  • можно ли удалять: perms & DELETE - 0, нельзя
  • выдать право: perms | DELETE, без новых таблиц и столбцов
  • так устроены, например, права ботов в Discord: одно число на все права

Что запомнить

  • двоичная запись: веса 1, 2, 4, 8, ...; bin(n), int(s, 2)
  • &, |, ^ считаются по каждому биту отдельно по таблице истинности
  • 1 << i - лампочка i, (n >> i) & 1 - горит ли она
  • набор чисел 1..n можно хранить одним числом: число x - бит x - 1
