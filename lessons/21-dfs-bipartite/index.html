Определение

Вершины разделены на два множества: L и R

  • Все рёбра идут между L и R
  • Рёбер внутри L или внутри R — нет

Как выглядит двудольный граф

Рёбра пересекают середину - ни одного внутри L или внутри R

Когда граф НЕ двудольный

Попробуем разделить треугольник A-B-C на два множества:

1
A кладём в L - ок
2
B - сосед A, значит в R
3
C - сосед A, значит в R
!
B и C соединены, но оба в R - противоречие!
Треугольник - нечётный цикл длины 3 - разделить невозможно
15

Как проверить?

признак двудольности

Признак двудольности

Граф двудольный тогда и только тогда, когда в нём нет нечётного цикла

Нечётный цикл

длина 3, 5, 7...

не двудольный

Чётный цикл

длина 4, 6, 8...

двудольный

Идея: 2-раскраска

  • Красим вершины в 2 цвета: красный и синий
  • Правило: сосед всегда другого цвета
  • Раскраска прошла без конфликтов - граф двудольный
  • L = все красные, R = все синие

Алгоритм 2-раскраски

через DFS

Алгоритм

1
Берём непосещённую вершину, даём ей цвет 0
2
Каждому непокрашенному соседу - цвет 1 - текущий, идём DFS
3
Сосед уже покрашен и цвет совпадает - конфликт, False
4
Повторяем для всех компонент - если нигде нет конфликта: True

Трассировка: квадрат

рёбра: 0-1, 1-2, 2-3, 3-0

2
color[2] = 0 (красный), DFS дальше
3
color[3] = 1 (синий). Сосед 0 красный - ок
✓
Конфликтов нет - граф двудольный
