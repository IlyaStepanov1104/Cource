DFS или BFS?

Практика: обход графов вперемешку. Занятие 29

Разбор ДЗ: 994. Rotting Oranges

Сетка клеток: 0 - пусто, 1 - свежий апельсин, 2 - гнилой. Каждую минуту гнилой заражает 4 соседние клетки.

Через сколько минут сгниют все? Если хоть один остался свежим - ответ -1.

Заражение расходится волной - это слово почти всегда означает BFS

Multi-source BFS

  • в клетках - минута заражения
  • все гнилые кладём в очередь сразу, до начала обхода
  • у всех них dist = 0
  • волна идёт от всех стартов одновременно
  • один BFS, а не отдельный запуск от каждого апельсина

Минуты - это номер слоя

Отдельный таймер не нужен: dist[клетка] и есть минута, когда она сгниёт. Ответ - максимум по всем dist.

❌ Ошибка раз

Вернуть число слоёв или число шагов очереди. Слоёв на единицу больше, чем минут: нулевой слой - это начало, а не первая минута

❌ Ошибка два

Забыть проверку в конце: если до какого-то свежего апельсина волна не дошла - ответ -1, а не максимум dist

Оставшиеся свежие удобно считать счётчиком: посчитали в начале, уменьшаем при каждом заражении. В конце счётчик не ноль - возвращаем -1

Что мы уже умеем

За прошлые занятия набрались три готовых каркаса. Нового алгоритма сегодня не будет - будет умение выбирать.

1
DFS - рекурсия или стек, обходит всё достижимое
2
BFS - очередь, обходит по слоям и попутно считает dist
3
Multi-source BFS - то же самое, но стартов в очереди сразу много
Навык занятия: прочитать условие и за 10 секунд понять, какой из трёх брать

Один граф, два порядка

DFS - вглубь

BFS - по слоям

Оба посетят все шесть вершин. Разница - в порядке и в том, что BFS попутно знает расстояние до каждой

Таблица-решалка

Что спрашивают Чем решаем
Кратчайший путь по числу рёбер или шагов BFS + dist
Есть ли путь, достижима ли вершина любой, проще DFS

Слова-маркеры в условии

  • "минимальное число ходов, шагов, минут, пересадок" - только BFS. DFS найдёт какой-то путь, но не самый короткий
  • "сколько групп, островов, компонент" - обход всего графа с внешним циклом по вершинам, годится DFS
  • "можно ли добраться, существует ли путь" - один запуск, всё равно какой обход
  • "ближайший выход, ближайшая единица" - снова BFS, часто multi-source
Слово "минимальное" рядом с невзвешенным графом - почти всегда BFS

Одна схема, два контейнера

Разница между DFS и BFS - одна строчка: с какого конца достаём следующую вершину.

DFS - стек

from collections import deque

def dfs(adj, start):
    visited = {start}
    todo = deque([start])
    order = []
    while todo:
        v = todo.pop()
        order.append(v)
        for to in adj[v]:
            if to not in visited:
                visited.add(to)
                todo.append(to)
    return order

pop() берёт последнюю добавленную - уходим вглубь

BFS - очередь

from collections import deque

def bfs(adj, start):
    visited = {start}
    todo = deque([start])
    order = []
    while todo:
        v = todo.popleft()
        order.append(v)
        for to in adj[v]:
            if to not in visited:
                visited.add(to)
                todo.append(to)
    return order

popleft() берёт первую добавленную - идём по слоям

Всё остальное совпадает построчно: visited, цикл по соседям, проверка перед добавлением. Помнить надо один каркас, а не два

Сетка

острова и кратчайший путь

200. Number of Islands

  • 1 - суша, 0 - вода
  • остров - клетки суши, связанные по 4 сторонам
  • на картинке 3 острова
  • вопрос: сколько островов всего
"Сколько групп" - это компоненты связности, задача с занятия 20 в новой обёртке

Как решаем

1
Идём по всем клеткам сетки двойным циклом
2
Встретили сушу, которой нет в visited - нашли новый остров, увеличиваем счётчик
3
Запускаем обход от этой клетки и помечаем весь остров целиком
4
Остальные клетки того же острова внешний цикл уже пропустит
Годится и DFS, и BFS: нам важно какие клетки достижимы, а не за сколько шагов. Порядок обхода на ответ не влияет

1091. Shortest Path in Binary Matrix

  • путь из левого верхнего в правый нижний угол
  • ходить можно только по нулям
  • соседей восемь, а не четыре - по диагонали тоже можно
  • длина пути - число посещённых клеток
Тут просят минимум, значит DFS отпадает: он найдёт какой-нибудь путь через полсетки и остановится на нём. Нужен BFS

Блиц

условие - и сразу ответ, чем решать

DFS или BFS?

  • Лабиринт, найти минимальное число шагов до выхода - BFS
  • Сколько друзей в социальной сети связаны с Петей напрямую или через знакомых - DFS, это компонента
  • Метро: минимум пересадок между станциями - BFS, рёбра невзвешенные
  • Можно ли расставить курсы так, чтобы не было противоречий - DFS, это поиск цикла
  • Для каждой клетки - расстояние до ближайшей воды - multi-source BFS от всех клеток воды
Проговаривай выбор вслух перед кодом: "минимум шагов - значит BFS". Это экономит полчаса переписывания

133. Clone Graph

Дан граф из объектов-вершин. Построить его копию: новые объекты, те же связи.

  • обходим граф любым обходом
  • заводим словарь старая вершина -> новая вершина
  • этот словарь работает и как visited: вершина есть в нём - копия уже создана
  • для каждого соседа берём его копию из словаря и связываем
Тот же приём, что с dist и parent: словарь вместо visited, только хранит не число, а объект
85

Что запомнить

  • Просят минимум шагов - BFS. Просят связность, компоненты или цикл - DFS. Просят порядок выхода - только DFS
  • DFS и BFS - один каркас, разница в контейнере: pop() против popleft()
  • Помечать вершину нужно при добавлении в очередь, иначе в очереди заводятся дубли
  • Несвязный граф - обход запускаем из внешнего цикла по всем вершинам
  • Словарь dist или parent часто заменяет visited и заодно хранит ответ
