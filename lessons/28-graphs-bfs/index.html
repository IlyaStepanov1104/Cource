BFS и кратчайший путь

Обход графа по слоям. Занятие 28

Разбор ДЗ: 332. Reconstruct Itinerary

Дан список авиабилетов [from, to]. Построить маршрут из "JFK", который использует каждый билет ровно один раз; при развилке - идти в лексикографически меньший город.

Билет - это ребро. Пройти каждое ребро по разу - эйлеров путь в ориентированном графе

Решение: тот же Хирхольцер на стеке. adj[city] отсортирован; идём жадно в первый доступный город, помечая билет использованным. У кого билетов не осталось - снимаем со стека в ответ. В конце ответ разворачиваем

Напоминание: как ходит DFS

Заходим в соседа и сразу ныряем вглубь по этой ветке, пока есть куда. Тупик - откат на шаг назад.

Порядок DFS: A -> B -> D -> C -> E -> F. К вершине C пришли длинным путём, хотя она сосед старта

Идея BFS: обход по слоям

BFS (breadth-first search, обход в ширину): сначала все соседи старта, потом соседи соседей, и так слой за слоем.

Как круги на воде от брошенного камня - волна расходится равномерно во все стороны

Тот же граф, разложенный по слоям

BFS посещает вершины строго по порядку расстояния от старта (в рёбрах): A, потом B и C, потом D и E, потом F

Зачем это нужно

DFS с таким порядком соседей уйдёт по верхней цепочке: S -> ... -> T за 4 ребра

DFS находит хоть какой-то путь. BFS находит путь с наименьшим числом рёбер - в невзвешенном графе это и есть кратчайший

Как работает BFS

очередь, состояния вершины, трассировка

Основа BFS - очередь

Очередь работает по правилу FIFO - кто первым вошёл, тот первым и выйдет.

Новые найденные вершины кладём в конец, обрабатываем с начала. Значит ближний слой обработается раньше дальнего - он попал в очередь первым 

from collections import deque

q = deque([start])   # q.append(x) - в конец, q.popleft() - с начала

Три состояния вершины

  • серая - не найдена, ещё не видели
  • жёлтая - лежит в очереди, ждёт обработки
  • зелёная - обработана, всех соседей просмотрели
Помечаем visited в момент попадания в очередь, а не обработки - иначе один сосед заедет в очередь несколько раз

Трассировка BFS от A

достаём A, кладём соседей: очередь [B, C]
достаём B, новый сосед D: очередь [C, D]
достаём C, новый сосед E: очередь [D, E]
достаём D, новый сосед F: очередь [E, F]
достаём E, потом F - новых нет. Очередь пуста, конец. Порядок: A B C D E F

Каркас обхода

from collections import deque

def bfs(adj, start):
    visited = {start}
    q = deque([start])
    while q:
        v = q.popleft()
        for to in adj[v]:
            if to not in visited:
                visited.add(to)
                q.append(to)
Тот же каркас, что у DFS - только вместо стека очередь, и берём элемент с другого конца (popleft вместо pop)

Кратчайший путь

dist, parent, сетка-лабиринт

Считаем расстояния: dist

Вместо множества visited заводим словарь dist: dist[start] = 0, у остальных значения пока нет.

Когда из v впервые попадаем в соседа to: dist[to] = dist[v] + 1 и кладём to в очередь. 

if to not in dist:
    dist[to] = dist[v] + 1
    q.append(to)
Наличие ключа в dist заменяет visited. Повторно вершину не трогаем - первое найденное значение уже минимальное

Почему это кратчайший путь

Очередь обрабатывает вершины по неубыванию dist: сначала весь слой 0, потом весь слой 1, потом слой 2.

Вершину to находим впервые из вершины слоя k - значит она в слое k + 1. Ближе быть не могло, иначе нашли бы раньше. Первое посещение = кратчайшее расстояние

Восстановление самого пути

dist даёт длину, но не сам маршрут. В тот же момент, когда ставим dist[to], запоминаем parent[to] = v - откуда пришли.

Чтобы получить путь до F: идём parent[F] -> parent[D] -> parent[B], пока не дойдём до старта, потом разворачиваем список 

path = []
cur = target
while cur is not None:
    path.append(cur)
    cur = parent.get(cur)
path.reverse()

Сетка-лабиринт - тот же граф

  • клетка = вершина
  • соседи - 4 клетки: смещения (-1,0) (1,0) (0,-1) (0,1)
  • стена и край - не сосед
  • список смежности строить не нужно, соседей считаем на лету
  • путь S - T за 8 шагов (синие клетки)
Multi-source BFS: можно положить в очередь сразу несколько стартов с dist = 0 - волна пойдёт от всех одновременно. ДЗ на это - 994. Rotting Oranges (ответ = номер последнего слоя)

  • обычный BFS, соседей клетки считаем через 4 смещения

Что запомнить

  • BFS = очередь + обход по слоям (в ширину), в отличие от DFS (в глубину)
  • В невзвешенном графе первое посещение вершины = кратчайший путь по числу рёбер; храним dist, ставим dist[to] = dist[v] + 1
  • Сам путь восстанавливаем через parent: идём от цели назад к старту и разворачиваем
  • Сетка-лабиринт - тот же граф (клетка = вершина, 4 соседа); multi-source BFS = несколько стартов в очереди сразу
  • ДЗ: 994. Rotting Oranges
