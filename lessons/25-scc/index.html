Что мы уже умеем

В неориентированном графе (занятия 20-23): компонента связности - максимальный кусок, где из любой вершины дойдёшь до любой другой.

Симметрия: можешь дойти - значит, можешь и вернуться по тем же рёбрам

В орграфе симметрии нет

Из A дойду до C. А обратно из C в A - никак.

«Связаны» ли A и C? Смотря в какую сторону идти. Нужно новое понятие.

Определение

Вершины u и v сильно связаны, если есть путь u -> v И путь v -> u
  • Компонента сильной связности (КСС) - максимальное множество попарно сильно связанных вершин
  • Это отношение эквивалентности - граф разбивается на КСС без пересечений
  • Английский термин - SCC, strongly connected component

Граф разбит на 3 КСС

Розовые рёбра между КСС ведут только в одну сторону: 2 -> 3, 4 -> 5

Ключевое свойство

  • Внутри КСС из любой вершины достижима любая другая - по определению
  • Между разными КСС связь только в одну сторону - иначе они слились бы в одну
КСС - это «острова взаимной досягаемости». Внутри острова гуляем свободно, между островами - только по одностороннему мостику
12

Алгоритм Косарайю

два обхода в глубину

Идея

  • Наивно: из каждой вершины DFS «туда» и DFS «обратно», пересечь. Это O(V * (V + E)) - медленно
  • Косарайю: всего два DFS
  • Первый - по обычному графу, чтобы понять порядок
  • Второй - по графу с развёрнутыми рёбрами

Шаг 1: порядок завершения

  • Запускаем DFS по исходному графу из каждой непосещённой вершины
  • Когда из вершины выходим (все соседи обработаны) - кладём её в стек
  • Тот же приём, что в топологической сортировке (занятие 20): порядок по времени выхода
Наверху стека окажется вершина, из которой DFS вышел последней

Шаг 2: развернуть рёбра

Транспонированный граф: было u -> v, стало v -> u.

Исходный

Транспонированный

Разбиение на КСС при развороте не меняется

Шаг 3: собираем КСС

1
Берём вершину с верха стека
2
Не посещена во втором обходе - запускаем DFS по транспонированному графу
3
Все, до кого дошли, - это одна КСС
4
Повторяем, пока стек не опустеет

Трассировка: пример

graph = {0:[1], 1:[2], 2:[0,3], 3:[4], 4:[5], 5:[3]}

Глазами: цикл 0-1-2, цикл 3-4-5, между ними односторонний мостик 2 -> 3. Ждём 2 КСС.

Первый DFS: идём вглубь

Путь вглубь из 0: 0 -> 1 -> 2 -> 3 -> 4 -> 5

Жёлтые пунктиром - 2 -> 0 и 5 -> 3: ведут в уже открытые вершины, назад по ним не идём

Первый DFS: заполняем стек по выходу

Вершина падает в стек, когда DFS из неё вышел. Порядок выхода: 5, 4, 3, 2, 1, 0

стек (снизу вверх): 5 4 3 2 1 0    сверху -> 0

Шаг 2 на примере: разворачиваем рёбра

Исходный граф

Транспонированный

radj = {0:[2], 1:[0], 2:[1], 3:[2,5], 4:[3], 5:[4]}

Мостик теперь 3 -> 2: «истоковая» КСС стала «стоковой»

Обратный DFS: снимаем со стека

1
Сверху стека - 0. Не посещена -> DFS по radj
2
0 -> 2 -> 1, дальше только в посещённые. Собрали {0, 1, 2}
3
Стек: 1 и 2 посещены, пропускаем. Следующая непосещённая - 3
4
3 -> 5 -> 4 (в 2 уже были). Собрали {3, 4, 5}
=
Стек пуст. Итог: 2 КСС

Почему это работает

  • Вершина, вышедшая последней, лежит в «истоковой» КСС - в неё нет рёбер снаружи
  • Во втором DFS рёбра развёрнуты: все выходы наружу теперь ведут внутрь
  • Значит обход из этой вершины заперт внутри её КСС - ровно её и соберём
  • Убрали КСС - следующая вершина в стеке снова «истоковая» для остатка

Строгое доказательство - в курсе алгоритмов; нам достаточно идеи

Сложность

Первый DFS O(V + E)
Разворот рёбер O(V + E)
Второй DFS O(V + E)
Итого O(V + E)
Линейно - как обычный обход. Плюс O(V + E) памяти на транспонированный граф

Конденсация

Ребро между КСС-узлами - если в графе было хоть одно ребро между их вершинами

Конденсация - всегда DAG

Пусть между КСС X и Y в конденсации есть цикл: из X дойдём до Y и обратно.

Тогда все вершины X и Y попарно сильно связаны - значит, это была одна КСС. Противоречие.

Циклов между КСС нет - значит конденсация это ориентированный граф без циклов (DAG)

Зачем сжимать

  • На DAG работают топологическая сортировка и динамика по вершинам (занятие 20)
  • Задачу про орграф с циклами сводим к задаче про DAG из КСС - она часто проще
  • Пример: «самый длинный путь» в орграфе с циклами не определён, а в конденсации - обычная динамика

Минимум рёбер до сильной связности

Сколько рёбер добавить, чтобы весь граф стал одной КСС?

a
Истоки конденсации (нет входящих) - их a
b
Стоки (нет исходящих) - их b
=
Ответ = max(a, b) (и 0, если КСС уже одна)

Где ещё пригодится

  • 2-SAT - выполнимость логических формул через КСС графа импликаций (позже в курсе)
  • «Какие пары вершин взаимно достижимы» - ответ читается по конденсации
  • Сжатие графа зависимостей: сборка, планировщики задач с циклами

Тот же вопрос для неографа

Можно ли так же сжать неориентированный граф - по «взаимной достижимости»?

Спойлер: можно, но получится пусто. Разберём, почему

Достижимость симметрична

  • В неографе: дошёл из u в v - по тем же рёбрам вернёшься из v в u
  • Значит «u и v взаимно достижимы» = «u и v в одной компоненте связности»
  • Ничего нового по сравнению с занятиями 20-23

Стягиваем компоненты - и что?

3 компоненты

Конденсация

Рёбер между разными компонентами нет по определению - остались 3 точки без единого ребра

Вывод: конденсация тривиальна

  • Вся информация в ней - одно число: сколько компонент
  • Его и так даёт один DFS/BFS или DSU (занятия 20, 23)
  • Отдельная структура не нужна - сжимать нечего

Откуда разница с орграфом

Достижимость Фактор
Орграф предпорядок (не симметричен) частичный порядок = DAG
Неограф сразу эквивалентность точки без рёбер
В орграфе направление кодирует зависимость - её и обнажает DAG. В неографе обнажать нечего

Содержательный аналог: дерево мостов

Стягиваем не компоненты связности, а компоненты рёберной двусвязности - куски без мостов внутри.

Дерево мостов

Мост не лежит на цикле - между стянутыми кусками остаются только мосты - получается дерево (занятие 24)

Задача 1: число КСС

Дан ориентированный граф списком смежности. Вернуть количество компонент сильной связности.

{0:[1], 1:[2], 2:[0], 3:[1,2,4], 4:[5], 5:[3]} ==> 2 КСС: {0,1,2} и {3,4,5}

Подсказка: это просто len(kosaraju(adj))

Задача 2: истоки и стоки конденсации

Построить конденсацию и вернуть (число истоков, число стоков).

  • Присвоить каждой вершине номер её КСС
  • Пройти по рёбрам: если концы в разных КСС - ребро конденсации
  • Исток - у КСС нет входящих; сток - нет исходящих
Отсюда один шаг до «минимума рёбер до сильной связности» = max(истоки, стоки)
56

Что запомнить

  • КСС - максимальное множество вершин, попарно достижимых друг из друга (u -> v и v -> u)
  • Косарайю: DFS со стеком по времени выхода, развернуть рёбра, DFS по стеку. O(V + E)
  • Конденсация (стянутые КСС) - всегда DAG; на нём работают топсорт и динамика
  • Неориентированный граф так не сжать (выйдет пусто); его аналог - дерево мостов из занятия 24
