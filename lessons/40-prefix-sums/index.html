Продажи по дням

Магазин записал выручку за пять дней:

Нужна выручка за разные периоды: дни 1–3, дни 0–2, дни 2–4.

Массив один. Вопросов к нему много.
Индексы с нуля. Пока периоды называем с включённым последним днём. Устно спросить выручку за дни 1–3: 1+4+2=7. Следующий слайд фиксирует удобную единую запись границ.

Договоримся о границах

[l, r): включаем l, не включаем r. Как в range(l, r).

Массив: [3, 1, 4, 2, 5].
Отрезок [1, 4): индексы 1, 2, 3. Сумма: 7.

  • Длина участка: r - l.
  • Весь массив: [0, len(a)).
  • Пустой участок: [l, l), сумма 0.
Не переходить между включённой и исключённой правой границей в задачах урока. Уточнить: день 4 не входит в [1,4). Если последний нужный индекс 3, правая граница равна 4.

Простой способ

Для каждого запроса заново проходим нужный участок и складываем его элементы.

Один запрос: до n сложений. q запросов: O(n · q) в худшем случае.

При n = 100 000 и q = 100 000 — до 10¹⁰ обработанных элементов.
Устно описать прямое суммирование, отдельной задачи нет. Спросить, решит ли проблему sum(a[l:r]). Нет: элементы всё равно просматриваются, а срез ещё создаёт список.

Что можно посчитать заранее?

Соседние запросы складывают одни и те же элементы снова и снова.

Сначала подготовка. Затем каждый ответ — из уже известных сумм.

Суммы от начала

сохраняем результат каждого шага

Что такое префикс?

Префикс — часть массива от его начала до выбранной границы.

Суффикс — часть массива от выбранной границы до его конца.

Подотрезок — непрерывная часть массива между двумя выбранными границами.

Сначала виден только длинный массив. Первый клик показывает синий префикс слева и определение внизу; второй — зелёный суффикс справа и определение; третий — жёлтый подотрезок и определение. Во всех трёх случаях элементы идут подряд, без пропусков. Префикс и суффикс — частные случаи подотрезка; внутренний участок выбран лишь для наглядности. Подотрезок может касаться любой границы или совпадать со всем массивом. Далее различить префикс как часть массива и prefix[k] как сумму первых k элементов.

Два массива — разные индексы

Индекс012345
a31425—
prefix03481015

prefix[3] = 8: сумма элементов a[0], a[1], a[2].

n элементов → n + 1 префиксная сумма.
Обратить внимание на сдвиг: a[i] прибавляется в prefix[i+1]. Для пустого массива prefix=[0]. До кода попросить вычислить prefix[4].

Добавляем один элемент

Новая префиксная сумма = предыдущая сумма + следующий элемент.

prefix[i + 1] = prefix[i] + a[i]

Один проход: O(n) времени и O(n) дополнительной памяти.
Ученик объясняет формулу накопления: к сумме первых i элементов добавляется элемент с индексом i. Реализацию преподаватель пишет в редакторе на следующем шаге.

Формула запроса

sum(l, r) = prefix[r] - prefix[l]

Например, для [1, 4): 10 − 3 = 7.

После подготовки один запрос занимает O(1).

Есть ли сумма target?

Дан массив целых чисел. Есть ли в нём непустой подотрезок с суммой target?

Массив: [3, −1, 4, −2]. Искомая сумма: 3.
Ответ: да — подходят [3] и [−1, 4].

Нужен линейный проход. Отрицательные числа разрешены.
Лайвкодинг преподавателя, 3_has_target_sum.py. Контракт: bool, пустой массив даёт False. Отрицательные числа не позволяют просто двигать границы по правилу «сумма велика — уменьшим окно». Спрашивать ученика о формуле суммы отрезка.

Какой префикс нам нужен?

prefix[r] - prefix[l] = target

Значит, ищем ранее встречавшуюся сумму:
prefix[l] = prefix[r] - target.

Идём слева направо. Множество хранит суммы только предыдущих префиксов.
Фиксируем правую границу r и ищем подходящую левую. Множество из темы хеш-таблиц. Не перебирать все l для каждого r. Начать с seen={0}, чтобы находить отрезки от начала массива.

Найдём совпадение

Массив: [2, −1, 3]. Искомая сумма: 2.

Текущая суммаИщем среди прошлыхНашли?
22 − 2 = 0Да: пустой префикс

Получили непустой отрезок [0, 1).

Если нужной суммы нет — запоминаем текущую и продолжаем.

Сначала проверяем, потом добавляем. Иначе target = 0 даст пустой отрезок.
Проверить устно [5],target=0: False. Если добавить 5 до проверки, получим ложное True. Дополнительная трассировка [2,-1,3],target=3: после сумм 2 и 1 приходит 4; 4-3=1 уже встречалась, отрезок [2,3).

Домашняя задача

от равных сумм — к равным остаткам

ДЗ: сумма делится на n

Дано мультимножество из n целых чисел, n ≥ 1.
Найди любое непустое подмножество, сумма которого делится на n.

Числа: [2, 2, 3], n = 3.
Можно выбрать элемент с индексом 2: его значение 3 делится на 3.

Верни список различных индексов. Каждое вхождение можно взять не больше одного раза.
ДЗ hw_divisible_subset.py. n=len(a), n>=1. Допускаются отрицательные числа и повторяющиеся значения. Подмножество мультимножества выбирает вхождения, поэтому возвращаем индексы. Любой порядок индексов допустим. Решение существует всегда; полный код и доказательство разбираются на следующем занятии.

Подсказка: посмотри на остатки

Упорядочим числа как в списке. Подойдёт и набор элементов одного подотрезка.

Если две префиксные суммы имеют одинаковый остаток по n, их разность делится на n.

Есть n + 1 префиксных сумм, включая 0, и только n возможных остатков. Что из этого следует?
Дать направление без полного решения. Ученик дома формулирует принцип Дирихле и восстанавливает индексы между двумя границами. Подотрезок в выбранном порядке является допустимым подмножеством мультимножества. Проверить, что ученик учитывает пустой префикс, но не возвращает пустое подмножество.

Что запомнить

  • prefix[k] хранит сумму первых k элементов.
  • Начинаем с 0: длина prefix равна n + 1.
  • Для [l, r): prefix[r] - prefix[l].
  • Для поиска отрезка запоминаем прошлые суммы и их границы.
58–60 минут. Попросить вывести формулу суммы, назвать нужный прошлый префикс для target и объяснить переход к разностям двух массивов. В ДЗ исследовать остатки и восстановить непустой набор индексов.
