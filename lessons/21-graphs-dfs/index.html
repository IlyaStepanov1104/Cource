Поиск в глубину

Depth-First Search

Идея: лабиринт

  • Идём вперёд как можно дальше
  • Тупик - возвращаемся, пробуем другой путь
  • Обязательно отмечаем пройденные комнаты
Без visited зациклимся навсегда - будем ходить по кругу

Трассировка DFS

graph = {'A': ['B','C'], 'B': ['D'], 'C': ['D'], 'D': []}
1
dfs(A) - посещаем A, идём в B
2
dfs(B) - посещаем B, идём в D
3
dfs(D) - посещаем D, нет соседей, возврат
4
Возврат в A, идём в C
5
dfs(C) - посещаем C, D уже в visited
Порядок вывода: A B D C

Применение: поиск цикла

Идея: если в ходе DFS мы встречаем вершину, которая уже в visited - значит, мы попали в неё по второму пути. Цикл.

A
->
B
->
C
->
A
!
Нюанс для неориентированного графа: вершина, из которой мы пришли - не считается. Иначе любое ребро выглядит как «цикл».

Скорость DFS

Сложность: O(V + E)

  • Каждую вершину посещаем ровно один раз - как только добавили в visited, второй раз не заходим
  • Каждое ребро смотрим ровно один раз - когда перебираем соседей вершины
V вершин + E рёбер = один проход по всему графу. Быстрее не бывает.

Топологическая сортировка

порядок задач с зависимостями

Задача

Есть задачи, у которых порядок важен. Нельзя начать задачу, пока не выполнены все её зависимости.

A
B
C
D
Правильный порядок: A - B - C - D или A - C - B - D

Где нужен топсорт

  • pip install - сначала зависимости, потом пакет
  • Сборка проекта - сначала модули без зависимостей
  • Расписание курсов - сначала базовые предметы
Работает только на DAG (Directed Acyclic Graph) - ориентированном графе без циклов

Алгоритм через DFS

Маленькое изменение в DFS:

  • Когда закончили обработку вершины (все соседи уже обойдены) - добавляем её в список
  • В конце разворачиваем список
Вершина попадает в список только после всех своих «потомков» - поэтому при развороте она оказывается раньше них

Трассировка

graph = {'A': ['B','C'], 'B': ['D'], 'C': ['D'], 'D': []}
1
dfs(A) → dfs(B) → dfs(D) → нет соседей → append(D)
2
Возврат в B, все соседи обработаны → append(B)
3
Возврат в A → dfs(C), D уже visited → append(C)
4
Возврат в A, все обработаны → append(A)
5
result = [D, B, C, A] → reverse = [A, C, B, D]

Практика

547. Number of Provinces

Дана матрица смежности n x n. isConnected[i][j] = 1 означает, что города i и j соединены. Найти количество провинций (связных компонент).

isConnected = [[1,1,0],
              [1,1,0],
              [0,0,1]]
# Ответ: 2 (города 0,1 связаны; город 2 - отдельно)
Подсказка: сконвертируй матрицу в список смежности и запусти DFS из каждой непосещённой вершины
88

Что запомнить

  • Граф = вершины + рёбра (ориентированный / взвешенный)
  • Список смежности - dict, ключ = вершина, значение = соседи
  • DFS - рекурсия + visited set, идём вглубь
  • Топологическая сортировка - добавляем вершину после всех соседей, разворачиваем
