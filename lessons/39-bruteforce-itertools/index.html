itertools

  • модуль стандартной библиотеки Python - устанавливать ничего не нужно
  • готовые инструменты для перебора: коды, перестановки, сочетания
  • выдают результаты по одному - их удобно обходить циклом for
Начнём с product: он повторяет выбор для каждой позиции.
Кратко представить модуль: он уже есть в Python, pip не нужен. Его инструменты возвращают итераторы, которые удобно обходить через for. Не углубляться в устройство итераторов; дальше сразу пример product.

product

from itertools import product

for chars in product("01", repeat=3):
    word = "".join(chars)
    print(word)

("0", "0", "1") → "001"

  • repeat=3 - три места, на каждом выбираем из "01"
  • вместо 3 можно написать length
Файл 4_product_codes.py. product возвращает кортежи; join собирает строку. Импорт из стандартной библиотеки, pip не нужен.

Считать или хранить?

from itertools import product

count = 0
for chars in product("012", repeat=5):
    if chars[0] != "0":
        count += 1
print(count)  # 162
  • product выдаёт варианты по одному
  • если нужен только ответ «сколько», список всех кодов не нужен
Файл 5_count_codes.py. Ответ: 2 × 3^4 = 162. product хранит входные наборы, но не все выходные кортежи.

Порядок и повторения

одни элементы - разные правила выбора

Три задачи

Есть три разных элемента: A, B, C. Каждый раз выбираем два.

  • код: составить строку из двух букв; буквы можно повторять
  • призовые места: назначить первое и второе место двум из трёх участников
  • команда: выбрать двух участников без распределения ролей
Где можно взять AA? Где AB и BA означают одно и то же?
Преподаватель объясняет три условия на одних обозначениях. В коде A, B, C - буквы, в двух остальных задачах - разные участники. В призовых местах один участник не может занять оба места. В команде порядок перечисления участников не важен. Затем сравнить результаты на следующем слайде.

Код, места или команда?

выбираем двоих из A, B, C что считается разным? всего
код AA можно; AB и BA разные 9
призовые места AA нельзя; AB и BA разные 6
команда AA нельзя; AB и BA - одно 3
Два вопроса: важен порядок? можно брать повторно?
Не вводить формулы факториалов. Все три примера можно перечислить руками. Исходные элементы различны.

permutations

permutations(items, k) перебирает все расстановки из k элементов: порядок важен, одну позицию входа дважды не берём.

from itertools import permutations

for pair in permutations("ABC", 2):
    print("".join(pair))

AB AC BA BC CA CB

  • AB и BA - разные расстановки
  • одну позицию входа дважды не берём; одинаковые буквы во входе могут дать дубли
Файл 8_arrangements.py. Пример с повторяющимися буквами объяснить устно: запрет относится к позиции, а не к значению.

combinations

combinations(items, k) перебирает все сочетания из k элементов: порядок не важен, одну позицию входа дважды не берём.

from itertools import combinations

for team in combinations("ABC", 2):
    print("".join(team))

AB AC BC

  • AB и BA - одна команда, второй раз не выдаём
  • буквы идут в порядке входа; сам вход не сортируется
Файл 9_teams.py. Один участник не может занять два места. Снова оговорить: вход без повторяющихся значений.

Что выбрать?

задача порядок повторения инструмент
PIN-код важен можно product
призовые места важен нельзя permutations
команда не важен нельзя combinations
Сначала правила задачи, потом название функции.
Ответы: product, permutations, combinations. Это классификация сегодняшних трёх случаев, не всех возможных задач.
